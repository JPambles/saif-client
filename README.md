> **Status: in development.** There is no public download yet. This repository is the project page and the place for **feedback, ideas and bug reports**. The source code is private for now.

## What SAIF Client is

- **Launcher (Windows):** sign in with your own Microsoft account, pick a Minecraft version and a profile, and press Play. SAIF installs everything itself; you don't need to install Forge or Fabric by hand.
- **In-game client:** a clean title screen, a **Quick Deck** (Right Shift) with search and shortcuts, and built-in mods: FPS, ping, keystrokes, CPS, coordinates, armor, potion timers, zoom, crosshair, chat filters, screenshot tools.
- **HUD editor:** drag, resize and snap widgets, with 3 saved layouts.
- **Themes:** Steel, Midnight and Sand, accent colors, high contrast, interface scale, plus installable theme and HUD packs.
- **Servers:** favorites, recent servers and live status inside the game.
- **Cosmetics:** original SAIF capes (visual only).
- **Versions:** 1.8.9 and 26.3 today; more versions are planned.

## Sign-in, safety and fair play

- You sign in on **Microsoft's own login page**. SAIF never sees your password.
- SAIF checks that your account **owns Minecraft** before you can play. There is **no offline or "cracked" mode**.
- Your login is stored in **Windows Credential Manager** and is never written to logs.
- Game files are downloaded only from **Mojang's official servers** and checked against Mojang's published hashes.
- SAIF does not give gameplay advantages that break server rules, and it respects servers that restrict mods. Cosmetics are visual only.
